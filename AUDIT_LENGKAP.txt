## 2. BACKEND API ROUTES (10 Endpoints)

Base URL: /api

SUBJECTS (/api/subjects)
  GET /api/subjects?limit=200 - List courses
  GET /api/subjects/:id - Get single course
  POST /api/subjects - Create course
  PATCH /api/subjects/:id - Update course
  DELETE /api/subjects/:id - Delete course
  
Validation: name required, credits non-negative, grade enum

TASKS (/api/tasks)
  GET /api/tasks?status=active - List tasks
  POST /api/tasks - Create task
  PATCH /api/tasks/:id - Update task
  DELETE /api/tasks/:id - Delete task
  
Fields: title, deadline, status, priority, estimated_hours, subject_id
Status enum: pending | in_progress | completed | cancelled
Priority enum: low | medium | high

EVENTS (/api/events)
  GET /api/events - List events
  POST /api/events - Create event
  PATCH /api/events/:id - Update event
  DELETE /api/events/:id - Delete event
  
Categories: tugas, ujian, kelas, acara

NOTES (/api/notes)
  GET /api/notes - List notes
  POST /api/notes - Create note
  PATCH /api/notes/:id - Update note
  DELETE /api/notes/:id - Delete note
  POST /api/notes/:id/export/:format - Export (pdf | markdown)
  
WARNING: PDF export requires html-pdf-node (may fail in serverless)

ANALYTICS (/api/analytics)
  GET /api/analytics - Returns active_tasks, completed_tasks, urgent_tasks

NOTIFICATIONS (/api/notifications)
  GET /api/notifications - Returns alerts within 48 hours

SEARCH (/api/search?q=query)
  GET /api/search - Global search across tasks, notes, subjects

UPLOAD (/api/upload)
  POST /api/upload - File upload to Vercel Blob
  Allowed: images, PDF, Office docs, text
  Max size: 5MB
  
SETTINGS (/api/dashboard-settings)
  GET /api/dashboard-settings - Get settings
  PUT /api/dashboard-settings - Update settings
  POST /api/pomodoro/increment - Increment pomodoro
  
HEALTH (/api/health)
  GET /api/health - Server health check

## 5. EXISTING ISSUES & COMMENTS

ISSUE 1: PDF Export May Fail in Serverless
  Location: backend/routes/notes.js (line 6-13)
  Problem: html-pdf-node requires Puppeteer/Chromium (too heavy)
  Impact: PDF export fails in production
  Fix: Use client-side rendering or cloud service

ISSUE 2: HTML Content Not Fully Sanitized
  Location: backend/routes/notes.js (line 142)
  Problem: Quill HTML stored as-is, XSS risk
  Recommendation: Use DOMPurify library

ISSUE 3: BroadcastChannel Not Universal
  Location: assets/js/shared-utils.js (line 30)
  Problem: Not supported in Safari <15.4, IE
  Impact: Cross-tab sync fails
  Workaround: Add polyfill

ISSUE 4: No Offline Support
  Missing: Service Worker, IndexedDB
  Impact: No data access when offline

ISSUE 5: Rate Limiting Too Permissive
  Location: backend/server.js (line 24-28)
  Current: 1000 req/15min
  Recommendation: Reduce to 100-200 req/min
